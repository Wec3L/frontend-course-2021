# Front-end Course 2021

HTML, CSS & JavaScript coursework from 2021 — my first steps in front-end development.

These are the homework assignments from a front-end course I took in 2021. They cover the fundamentals: Git basics, semantic HTML, CSS selectors and the box model, float/inline-block layouts, landing-page markup from design mockups, responsive design with media queries, custom fonts, and JavaScript basics.

Each assignment originally lived in its own repository; they were merged here with `git subtree`, so the original commit history and dates are preserved.

**Live previews:** every folder is served with GitHub Pages — https://wec3l.github.io/frontend-course-2021/
